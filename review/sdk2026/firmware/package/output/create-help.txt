
Usage: /offline-package/commander-cli/commander-cli gbl3 create <filename> [options]

Create a GBL3 file.

Options:
  -v, --version                           Displays version information.
  -h, --help                              Displays help on commandline options.
  --help-all                              Displays help including Qt specific
                                          options.
  --device, -d <device>                   The device, device family or platform
                                          to target. Examples of strings that
                                          are understood:
                                          "EFR32MG1P233F256GM48", "EFR32MG",
                                          "EFR32", "EFR32F256". Required for
                                          some operations.
  --force                                 Force operation. This will convert
                                          non-fatal errors to warnings, allowing
                                          the process to continue.
  --timestamp                             Add timestamp to Commander output.
  --json                                  Show output in JSON format.
  --app <app image>                       Application image to use when
                                          generating GBL3.
  --bootloader <bootloader image>         Bootloader image to use when
                                          generating GBL3 with bootloader
                                          upgrade support.
  --seupgrade <SE upgrade image>          Secure Engine upgrade image (provided
                                          by Silicon Labs).
  --metadata <metadata bin file>          Metadata binary to add to the GBL3
                                          file.
  --compress <app compression algorithm>  Which compression algorithm to use
                                          for application image. Supported
                                          algorithms: lz4, lzma
  --certificate <certificate file>        Certificate to add to the GBL3 file.
  --include-section <section>             Section to include from Elf file.
  --exclude-section <section>             Section to exclude from Elf file.
  --seunencrypted                         Places the SE upgrade binary outside
                                          the encrypted area of the GBL3 file.
  --dep-app <statement:version>           Set version dependency of application
                                          image. Supported dependency
                                          statements: 'l/leq/eq/geq/g' for less
                                          than/less than or equal/equal/greater
                                          than or equal/greater than,
                                          respectively.  Version should be an
                                          uint 32 number.
  --dep-boot <statement:version>          Set version dependency of bootloader
                                          image. Supported dependency
                                          statements: 'l/leq/eq/geq/g' for less
                                          than/less than or equal/equal/greater
                                          than or equal/greater than,
                                          respectively. Version should be given
                                          in the following format:
                                          'major.minor.patch'.
  --dep-se <statement:version>            Set version dependency of SE upgrade
                                          image. Supported dependency
                                          statements: 'l/leq/eq/geq/g' for less
                                          than/less than or equal/equal/greater
                                          than or equal/greater than,
                                          respectively. Version should be given
                                          in the following format:
                                          'major.minor.patch'.
  --delta-app <app image>                 Create delta-upgrade GBL3 from this
                                          application. Used in conjunction with
                                          --app.
  --sign <key file>                       Sign the GBL3 output file using an
                                          ECC-P256 PEM private key file to
                                          generate the signature.
  --encrypt <AES key file>                Encrypt the GBL3 output. A key file
                                          can be generated by running 'gbl3
                                          keygen --type aes-ccm'.
  --extsign                               Generate a .extsign output file
                                          instead of a regular GBL3 file. This
                                          file can be used to compute a
                                          signature over the entire binary which
                                          can later be inserted in the file
                                          using the 'gbl3 sign' command.
  --extencrypt                            Generate a .extencrypt output file,
                                          along with a .header and .footer file,
                                          instead of a regular GBL3 file. The
                                          .extencrypt file can be encrypted
                                          using an external tool. The .header
                                          and .footer files are later used to
                                          construct the final encrypted GBL file
                                          using the 'gbl3 encrypt' command.

Arguments:
  gbl3                                    Create, parse and other handling for
                                          GBL3 files
  create                                  Create a GBL3 file.
  filename                                Output GBL3 file.
